# Distribution status

[English](RELEASE.md) | [Français](RELEASE.fr.md)

This repository publishes experimental **sources** of Parole 0.1.2. It does
not provide an official public installer, model weights or a browser-only app.
The desktop interface is currently French; repository documentation is English
and French. English UI/installer localisation is not claimed.

Some code has been exercised in private platform trials. That is not global
acceptance of all workflows, target machines, long meetings or generated text
quality. This publication is not a version 1.0 announcement.

A future binary release needs a target-specific inventory of native engines,
runtime libraries, models, full notices, source obligations and checksums,
plus real installation and operation tests. Signing/notarisation and any paid
certificates require a separate decision. Do not recommend an unrelated old
archive as an official build, or bypass managed-device protections.

The source checks described in [TESTING.md](TESTING.md) are narrower and
reproducible without model downloads. Security fixes and platform support have
no promised response time; see [SECURITY.md](SECURITY.md).
